# Macrae Health

Mobile-first PWA starter for personal fitness, nutrition and recovery.

## Current prototype features
- Macrae tartan/stag visual identity
- Workout framework and manual unscheduled workout logging
- Manual food diary with calorie and macro totals
- Weight, sleep and readiness check-ins
- Local progress photo diary
- JSON backup export
- PWA manifest and offline service worker

## Not yet connected
AI-generated plans, automatic nutrition-label OCR, secure cloud photo storage, account sync, health-device integrations and two-way calendar scheduling require backend services and explicit integration setup. Browser-local data is not encrypted medical storage. Provisional calorie and protein figures are estimates, not medical prescriptions. Previous fatty liver history should be reviewed with a GP before starting supplements.
