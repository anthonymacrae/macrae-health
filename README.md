# Macrae Health

Mobile-first personal fitness, nutrition and recovery tracker (PWA).

## Current features
- Macrae tartan/stag visual identity
- Dashboard using the user's recorded gym baseline: 98.6 kg, estimated 31% body fat, reported machine muscle reading 37%, hydration 50%, BMR estimate 1,850 kcal/day
- Daily food diary with calorie and macro totals and 150 g protein target
- Initial 2,200 kcal/day planning guide, to be reviewed against real-world progress
- Three-day beginner gym programme with back-conscious exercise selection
- Workout logging and exercise set logging (weight, reps and sets)
- Staged squat progression; loaded barbell squats are deferred pending assessment of recurring back pain
- Weight, waist and optional body-fat measurements with a simple weight trend chart
- Local progress photo diary
- Sleep, energy and back-discomfort check-ins
- Weekly shopping checklist
- JSON backup export and restore
- PWA manifest and offline service worker

## Data and privacy
Entries are stored in browser localStorage on the device. This is not encrypted medical storage and there is no cloud sync. Export backups regularly. Progress photos may consume browser storage.

## Health and nutrition notes
Calorie and body-composition values are estimates, not diagnoses or prescriptions. The 2,200 kcal and 150 g protein targets are starting guides and should be reviewed after 2–3 weeks. The user reports recurrent lower and middle back pain without a diagnosis; heavy barbell squats should wait until clinical assessment and appropriate guidance. Stop movements that increase pain. Seek urgent assessment for new neurological red flags.

## Not yet connected
AI coaching, barcode/label OCR, cloud sync, secure photo storage, wearable integrations and calendar scheduling require additional backend services and explicit integration setup.
